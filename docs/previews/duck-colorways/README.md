# Duck material previews

Preview-only native Three.js renders of the real Microduck rigs, with fixed pose, lighting and a simplified playground-colored stage. Not screenshots of the live console. No production materials changed.

1. Sunshine & Sky: Pip #EFB832, Nova #429FC4
2. Coral & Lagoon: Pip #E78467, Nova #268D98
3. Peach & Periwinkle: Pip #EAAA7A, Nova #8584CE
4. Cream & Cobalt: Pip #DFCDB0, Nova #356BCB

All use ivory #FFF1D7 neutral panels and dark #283D48 mechanics. Preview applies accent colors to shell and colored feet/details; matching the selected preview in production requires extending the current shell-only tint mapping. PNGs are ready to view. preview.html is the rendering source; its absolute module imports require serving from the web Vite origin (not file://). User subsequently selected dark grey (#454B54) for Pip and navy (#244267) for Nova. Applied in the live rig with cool light panels (#E4E6E5); selected/ contains a render of the updated materials without preview overrides.
